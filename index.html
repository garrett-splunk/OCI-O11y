Hands-on lab · ~35 minutes

OCI Connector Hub → Splunk Observability Cloud

Two integration paths: logs via OCI Streaming + SOC4Kafka → otlphttp, and metrics via OCI Monitoring + Function → /v2/datapoint. Local Redpanda and Python simulators stand in for OCI services.

Key idea

Connector Hub does not speak OTLP. OCI moves logs to Streaming; your collector consumes Kafka and exports OTLP to Splunk.

1 — Prerequisites

  • Docker Desktop or Docker Engine + Compose v2
  • Splunk Observability Cloud ingest token (Organization Settings → Access Tokens)
  • Realm URLs matching your org (e.g. us0, us1, eu0)
Clone and enter lab 
git clone https://github.com/garrett-splunk/OCI-O11y.git
cd OCI-O11y/lab

2 — Start the local stack

Redpanda provides a Kafka-compatible broker; the collector joins consumer group oci-o11y-lab.

lab/scripts/start.sh

./scripts/verify-stack.sh

4 — Wire the collector

Config file: lab/collector/otelcol-config.yaml — SOC4Kafka pattern with O11y sink instead of HEC.

collector/otelcol-config.yaml — core blocks 
receivers:
  kafka:
    brokers: ["${env:KAFKA_BOOTSTRAP}"]
    group_id: ${env:KAFKA_CONSUMER_GROUP}
    logs:
      topics: ["${env:KAFKA_TOPIC}"]
      encoding: text

processors:
  resource/oci_lab:
    attributes:
      - key: deployment.environment.name
        value: oci-connector-lab
        action: upsert
      - key: cloud.provider
        value: oci
        action: upsert

exporters:
  otlphttp/o11y_logs:
    logs_endpoint: ${env:SPLUNK_INGEST_URL}/v3/event
    headers:
      X-SF-Token: ${env:SPLUNK_ACCESS_TOKEN}

service:
  pipelines:
    logs:
      receivers: [kafka]
      processors: [memory_limiter, resource/oci_lab, batch]
      exporters: [otlphttp/o11y_logs]

Production variant with SASL: collector/otelbin-examples/oci-production.yaml

Troubleshooting

Collector fails to start

Use collector v0.155.0+ for kafka logs receiver. Exporter type is otlphttp (not otlp_http).

HTTP 401 on export

Fix SPLUNK_ACCESS_TOKEN in .env.splunk, then docker compose restart otel-collector.

Debug shows logs but UI empty

Widen time range; try filter without dimensions first; confirm token has log ingest scope.

No messages consumed

Run ./scripts/produce-oci-logs.sh after collector is healthy. Check docker compose logs otel-collector for kafka consumer group join.

Teardown

Stop and remove volumes 
./scripts/teardown-lab.sh
